# Harmat 22 v2.5 Stable

Date: 2026-05-30

## Scope

This release records the current stable public-site polish used on harmat22.hu after the homepage and virtual-selector cleanup.

## Changes

- Added the live mu-plugin snapshot under `wp-mu-plugins/harmat-performance-guard.php`.
- Kept the homepage virtual-selector preview lightweight by using a static first-frame image that links to the full virtual apartment selector.
- Removed the experimental green-overlay preview from the homepage entry card.
- Fixed mobile layout on virtual building pages such as `/virtualis-lakasvalaszto-a1-epulet/` so apartment cards stack below the viewer instead of being pushed off to the side.
- Preserved the public frontend behavior while keeping heavy interactive selector logic on the dedicated virtual-selector pages.
