# Harmat 22 v2.3

Date: 2026-05-13

## Scope

This release documents the public apartment-search rebuild and related launch cleanups currently active on harmat22.hu.

## Changes

- Rebuilt `lakaskereso` public listing from the unified sales data source.
- Public listing now renders all 124 apartments instead of the legacy 31-card Elementor loop.
- Removed the legacy Elementor listing from the public DOM after the unified list takes over.
- Added anti-flicker styles so the old listing does not flash before the new list appears.
- Added compact desktop listing layout:
  - 4 cards per row on desktop.
  - 3 cards below 1180px.
  - 2 cards on tablet.
  - 1 card on mobile.
- Restored compact image sizing for listing cards.
- Fixed listing images so lazy-load SVG placeholders are ignored.
- Continued hidden-price behavior on public listing cards.
- Kept `/property/` redirected to `/lakaskereso/`.
- Preserved virtual apartment selector public access and unified-data rendering.
- Unified visible brand wording from `Harmat 22 Lakópark` to `Harmat Lakópark` where appropriate.
