# Harmat22 Website Maintenance

This repository is used to track maintenance notes, safe frontend changes, and deployment-related scripts for harmat22.hu.

## Working Rules

- Do not commit WordPress login cookies, SSH keys, raw backups, exported videos, PDFs, screenshots, or downloaded HTML snapshots.
- Keep each website change in a small, named commit so it can be reviewed and rolled back.
- Store production backups outside GitHub unless a sanitized text note is needed.

## Current Focus

- Frontend polish and layout fixes
- Property page and floorplan corrections
- Contact form testing and legal compliance text
- Cache-aware verification after each live change
